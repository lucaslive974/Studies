# C++ Idioms and Patterns

This is my personal repository for studying C++ design patterns, idioms, and advanced language features. While primarily built for my own learning, I hope it serves as a useful reference for anyone looking to understand these concepts in practice.

---

## 🧠 Idioms
Practical examples of commonly used C++ architectural patterns:

* **CRTP** (Curiously Recurring Template Pattern)
* **Mixin** (Mixin Classes / Multiple Inheritance)
* **PIMPL** (Pointer to Implementation / Compilation Firewalls)

## ⚙️ Modern C++ Features
Explorations of template metaprogramming and modern language capabilities:

* **Type Traits** 
* **SFINAE** (Substitution Failure Is Not An Error)
* **Concepts** (C++20 Template Constraints)

## 💻 LeetCode
* **Problem Solving:** Practical application of modern C++ techniques and data structures to solve algorithmic challenges from LeetCode.
